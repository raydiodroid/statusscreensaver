## 1. 项目概述

### 1.1 项目背景

开发一个屏幕保护程序控制系统，能够：
- 在 Windows 系统上全屏展示多种内容（图片、视频、时钟等）
- 支持 WebHook 远程控制
- 支持多设备同步切换
- 部署在公司内网，接收外部通知

### 1.2 核心功能

| 功能 | 描述 |
|------|------|
| 内容展示 | 支持图片、视频、时钟等多种展示类型 |
| 定时轮播 | 按配置自动循环切换内容 |
| 远程控制 | 通过 WebHook 触发切换、暂停等操作 |
| 多设备同步 | 多个屏幕同时切换到相同内容（触发同步，各设备独立播放） |
| 离线运行 | 内网环境也能正常运行，支持无服务器模式 |
| 混合运行 | 支持系统屏保模式 + 常驻应用模式双模式运行 |
| 内容远程更新 | 支持手动替换 + 远程下载两种内容更新方式 |

### 3.3 IPC 通信设计

#### 3.3.1 通信协议

使用 **命名管道 (Named Pipe)** 实现 IPC 通信：

```
管道名称: \\.\pipe\screensaver_ipc
通信格式: JSON
传输方向: 双向（请求-响应 + 推送）
```

#### 3.3.2 消息类型

**请求-响应消息（.scr → 常驻应用）：**

| 请求类型 | 说明 | 请求示例 | 响应示例 |
|----------|------|----------|----------|
| `get_content` | 获取当前内容 | `{"type": "get_content"}` | `{"type": "content", "data": {"type": "image", "path": "..."}}` |
| `get_playlist` | 获取播放列表 | `{"type": "get_playlist"}` | `{"type": "playlist", "data": [...]}` |
| `report_status` | 上报状态 | `{"type": "report_status", "data": {"playing": true}}` | `{"type": "ack"}` |

**推送消息（常驻应用 → .scr）：**

| 推送类型 | 说明 | 消息示例 |
|----------|------|----------|
| `switch_content` | 切换内容 | `{"type": "switch_content", "index": 2}` |
| `content_update` | 内容更新 | `{"type": "content_update", "content": {...}}` |
| `pause` | 暂停播放 | `{"type": "pause"}` |
| `resume` | 恢复播放 | `{"type": "resume"}` |

### 3.4 混合运行模式

#### 3.4.1 运行模式对比

| 模式 | 触发方式 | 用户活动后 | WebSocket | 使用场景 |
|------|----------|------------|-----------|----------|
| **系统屏保模式** | Windows 空闲检测自动启动 | .scr 关闭，常驻应用托盘继续运行 | 由常驻应用维护 | 默认模式 |
| **常驻应用模式** | 托盘图标双击 | ESC 退出全屏，回到托盘 | 保持连接 | 手动控制/调试 |

## 4. 技术选型

### 4.1 为什么选择 WebSocket

| 方案 | 服务器能否主动推送？ | 实时性 | 资源消耗 | 内网兼容性 |
|------|---------------------|--------|----------|-----------|
| 短轮询 | ❌ 不能 | 低（延迟 3-5 秒） | 高（频繁请求） | ✅ |
| 长轮询 | ⚠️ 半推 | 中（延迟 ~0.5 秒） | 中 | ✅ |
| **WebSocket** | ✅ 能 | 高（< 50ms） | 低（单连接） | ✅ |

**结论：WebSocket 是最佳选择**
- 实时推送，延迟极低
- 资源消耗小，一条 TCP 连接
- 内网主动向外连接，安全无问题
- 支持双向通信，设备可上报状态

### 4.2 技术栈

| 组件 | 技术选型 | 版本要求 | 说明 |
|------|----------|----------|------|
| **客户端 UI** | PyQt6 | >= 6.5.0 | 跨平台 GUI 框架，支持视频播放 |
| **视频播放** | PyQt6-QtMultimedia | >= 6.5.0 | Qt 多媒体模块，依赖系统编解码器 |
| **WebSocket 客户端** | websockets | >= 11.0 | Python WebSocket 库 |
| **IPC 通信** | pywin32 | >= 305 | Windows 命名管道 |
| **JWT 认证** | PyJWT | >= 2.0.0 | Token 生成与验证 |
| **服务端框架** | FastAPI | >= 0.100.0 | 高性能异步 Web 框架 |
| **服务端 ASGI** | Uvicorn | >= 0.23.0 | ASGI 服务器 |
| **配置管理** | PyYAML | >= 6.0 | YAML 解析 |

### 4.3 视频格式支持

使用 PyQt6-QtMultimedia 播放视频，依赖 Windows 系统编解码器：

| 格式 | 支持 | 说明 |
|------|------|------|
| MP4 (H.264) | ✅ 推荐 | 最佳兼容性 |
| WMV | ✅ 推荐 | Windows 原生 |
| AVI | ✅ 支持 | 常见编码 |
| MP4 (H.265) | ⚠️ 部分 | 部分系统需扩展 |
| WebM/MKV | ❌ 不支持 | 需用户转码 |

### 4.4 为什么选择双进程架构

| 方案 | 优点 | 缺点 |
|------|------|------|
| **双进程架构** | 职责分离、IPC 解耦、稳定可靠 | 需要进程间通信 |
| 单进程多窗口 | 实现简单 | 系统屏保模式难以集成 |
| 纯系统屏保 | Windows 原生集成 | 无法实时响应远程指令 |

```python
"""
IPC 服务端模块 - 使用命名管道与 .scr 屏保通信
"""

import json
import threading
import logging
import win32pipe
import win32file
import pywintypes

logger = logging.getLogger(__name__)

class IPCServer:
    """IPC 服务端"""
    
    def __init__(self, config: dict):
        self.pipe_name = config.get("pipe_name", "screensaver_ipc")
        self.max_clients = config.get("max_clients", 5)
        self.running = False
        self.clients = {}
        self.on_request = None
        self._thread = None
    
    def start(self):
        """启动 IPC 服务"""
        self.running = True
        self._thread = threading.Thread(target=self._run_server, daemon=True)
        self._thread.start()
        logger.info(f"IPC 服务端已启动: {self.pipe_name}")
    
    def stop(self):
        """停止 IPC 服务"""
        self.running = False
        logger.info("IPC 服务端已停止")
    
    def _run_server(self):
        """运行服务主循环"""
        while self.running:
            try:
                self._handle_client()
            except Exception as e:
                logger.error(f"IPC 服务错误: {e}")
    
    def _handle_client(self):
        """处理客户端连接"""
        pipe_path = f"\\\\.\\pipe\\{self.pipe_name}"
        
        # 创建命名管道
        pipe = win32pipe.CreateNamedPipe(
            pipe_path,
            win32pipe.PIPE_ACCESS_DUPLEX,
            win32pipe.PIPE_TYPE_MESSAGE | win32pipe.PIPE_READMODE_MESSAGE | win32pipe.PIPE_WAIT,
            self.max_clients,
            65536, 65536,
            0, None
        )
        
        try:
            # 等待客户端连接
            win32pipe.ConnectNamedPipe(pipe, None)
            logger.info("IPC 客户端已连接")
            
            # 处理消息
            while self.running:
                try:
                    # 读取消息
                    result, data = win32file.ReadFile(pipe, 65536)
                    message = data.decode('utf-8')
                    
                    # 处理请求
                    response = self._process_message(message)
                    
                    # 发送响应
                    win32file.WriteFile(pipe, response.encode('utf-8'))
                    
                except pywintypes.error as e:
                    if e.winerror == 109:  # 管道已关闭
                        break
                    raise
                    
        finally:
            win32file.CloseHandle(pipe)
            logger.info("IPC 客户端已断开")
    
    def _process_message(self, message: str) -> str:
        """处理消息"""
        try:
            request = json.loads(message)
            
            if self.on_request:
                response = self.on_request(request)
            else:
                response = {"type": "error", "message": "No handler"}
            
            return json.dumps(response)
            
        except json.JSONDecodeError:
            return json.dumps({"type": "error", "message": "Invalid JSON"})
    
    def broadcast(self, message: dict):
        """向所有连接的客户端推送消息"""
        # 注意：命名管道不支持主动推送，需要客户端轮询
```

```python
"""

import json
import logging
from pathlib import Path
from datetime import datetime

logger = logging.getLogger(__name__)


class StateManager:
    """状态管理器"""
    
    def __init__(self, config: dict):
        self.state_file = Path(config.get("file", "state.json"))
        self.state = {
            "device_id": None,
            "token": None,
            "current_index": 0,
            "last_content": None,
            "last_status": None,
            "last_update": None
        }
    
    def load(self):
        """从文件加载状态"""
        if self.state_file.exists():
            try:
                with open(self.state_file, 'r', encoding='utf-8') as f:
                    loaded = json.load(f)
                    self.state.update(loaded)
                logger.info("状态已从文件加载")
            except Exception as e:
                logger.error(f"加载状态失败: {e}")
    
    def save(self):
        """保存状态到文件"""
        try:
            self.state["last_update"] = datetime.now().isoformat()
            with open(self.state_file, 'w', encoding='utf-8') as f:
                json.dump(self.state, f, indent=2, ensure_ascii=False)
            logger.debug("状态已保存")
        except Exception as e:
            logger.error(f"保存状态失败: {e}")
    
    def update(self, key: str, value):
        """更新状态"""
        self.state[key] = value
    
    def get(self, key: str, default=None):
        """获取状态"""
        return self.state.get(key, default)
    
    def reset(self):
        """重置状态"""
        self.state = {
            "device_id": None,
            "token": None,
            "current_index": 0,
            "last_content": None,
            "last_status": None,
            "last_update": datetime.now().isoformat()
        }
```

```python
"""
IPC 客户端模块
"""

import json
import threading
import time
import logging
import win32file
import pywintypes

logger = logging.getLogger(__name__)


class IPCClient:
    """IPC 客户端"""
    
    def __init__(self, config: dict):
        self.pipe_name = config.get("pipe_name", "screensaver_ipc")
        self.connected = False
        self.pipe = None
        self._listener = None
        self._running = False
        
        # 回调
        self.on_switch_content = None
        self.on_content_update = None
        self.on_pause = None
        self.on_resume = None
    
    def connect(self) -> bool:
        """连接到服务端"""
        pipe_path = f"\\\\.\\pipe\\{self.pipe_name}"
        
        try:
            self.pipe = win32file.CreateFile(
                pipe_path,
                win32file.GENERIC_READ | win32file.GENERIC_WRITE,
                0, None,
                win32file.OPEN_EXISTING,
                0, None
            )
            
            # 设置消息模式
            win32file.SetNamedPipeHandleState(
                self.pipe,
                win32file.PIPE_READMODE_MESSAGE,
                None, None
            )
            
            self.connected = True
            self._running = True
            
            # 启动监听线程
            self._listener = threading.Thread(target=self._listen, daemon=True)
            self._listener.start()
            
            logger.info("已连接到 IPC 服务端")
            return True
            
        except pywintypes.error as e:
            logger.error(f"连接 IPC 服务端失败: {e}")
            return False
    
    def disconnect(self):
        """断开连接"""
        self._running = False
        self.connected = False
        if self.pipe:
            win32file.CloseHandle(self.pipe)
        logger.info("已断开 IPC 连接")
    
    def request(self, request_type: str, data: dict = None) -> dict:
        """发送请求并等待响应"""
        if not self.connected:
            return None
        
        message = {"type": request_type}
        if data:
            message.update(data)
        
        try:
            # 发送请求
            win32file.WriteFile(self.pipe, json.dumps(message).encode('utf-8'))
            
            # 接收响应
            result, response = win32file.ReadFile(self.pipe, 65536)
            return json.loads(response.decode('utf-8'))
            
        except Exception as e:
            logger.error(f"IPC 请求失败: {e}")
            return None
    
    def _listen(self):
        """监听推送消息"""
        while self._running and self.connected:
            try:
                # 发送心跳请求，获取可能的推送消息
                time.sleep(1)
            except Exception:
                break
```

```python
"""
WebSocket 客户端模块
"""

import asyncio
import json
import threading
import time
import uuid
import logging
from typing import Callable, Optional
import websockets
from websockets.exceptions import ConnectionClosed

logger = logging.getLogger(__name__)


class WebSocketClient:
    """WebSocket 客户端"""
    
    def __init__(
        self,
        server_url: str,
        token: str = None,
        device_name: str = "Unknown",
        device_location: str = None,
        heartbeat_interval: float = 30.0,
        reconnect_interval: float = 5.0
    ):
        self.server_url = server_url
        self.token = token
        self.device_name = device_name
        self.device_location = device_location
        self.heartbeat_interval = heartbeat_interval
        self.reconnect_interval = reconnect_interval
        
        # 设备 ID（注册后由服务器分配）
        self.device_id: Optional[str] = None
        
        # 连接状态
        self.connected = False
        self.running = False
        
        # 回调函数
        self.on_command: Optional[Callable] = None
        self.on_connected: Optional[Callable] = None
        self.on_disconnected: Optional[Callable] = None
        
        # WebSocket 连接
        self._ws = None
        self._loop = None
        self._thread = None
    
    def start(self):
        """启动客户端"""
        if self.running:
            return
        
        self.running = True
        self._thread = threading.Thread(target=self._run_loop, daemon=True)
        self._thread.start()
        logger.info("WebSocket 客户端线程已启动")
    
    def stop(self):
        """停止客户端"""
        self.running = False
        if self._loop:
            asyncio.run_coroutine_threadsafe(self._disconnect(), self._loop)
        logger.info("WebSocket 客户端已停止")
    
    def _run_loop(self):
        """主循环（在独立线程中运行）"""
        self._loop = asyncio.new_event_loop()
        asyncio.set_event_loop(self._loop)
        
        while self.running:
            try:
                self._loop.run_until_complete(self._connect_and_run())
            except Exception as e:
                logger.error(f"连接错误: {e}")
            
            if self.running:
                logger.info(f"{self.reconnect_interval}秒后重连...")
                time.sleep(self.reconnect_interval)
    
    async def _connect_and_run(self):
        """建立连接并运行"""
        headers = {}
        if self.token:
            headers["Authorization"] = f"Bearer {self.token}"
        
        try:
            async with websockets.connect(
                self.server_url,
                extra_headers=headers,
                ping_interval=None,  # 我们自己管理心跳
                close_timeout=5
            ) as ws:
                self._ws = ws
                self.connected = True
                
                # 发送注册消息
                await self._register()
                
                # 连接成功回调
                if self.on_connected:
                    self.on_connected(self.device_id)
                
                logger.info(f"已连接到服务器: {self.server_url}")
                
                # 启动心跳任务
                heartbeat_task = asyncio.create_task(self._heartbeat_loop())
                
                # 接收消息循环
                try:
                    async for message in ws:
                        await self._handle_message(message)
                except ConnectionClosed:
                    pass
                finally:
                    heartbeat_task.cancel()
                    
        except Exception as e:
            logger.error(f"连接失败: {e}")
        finally:
            self.connected = False
            self._ws = None
            
            if self.on_disconnected:
                self.on_disconnected()
    
    async def _register(self):
        """向服务器注册设备"""
        register_msg = {
            "type": "register",
            "name": self.device_name,
            "location": self.device_location
        }
        await self._ws.send(json.dumps(register_msg))
    
    async def _heartbeat_loop(self):
        """心跳循环"""
        while self.connected and self.running:
            try:
                await asyncio.sleep(self.heartbeat_interval)
                if self._ws:
                    await self._ws.send(json.dumps({"type": "ping"}))
            except asyncio.CancelledError:
                break
            except Exception as e:
                logger.error(f"心跳发送失败: {e}")
                break
    
    async def _handle_message(self, message: str):
        """处理收到的消息"""
        try:
            data = json.loads(message)
            msg_type = data.get("type")
            
            if msg_type == "register_ack":
                # 注册确认
                self.device_id = data.get("device_id")
                logger.info(f"设备注册成功: {self.device_id}")
                
            elif msg_type == "pong":
                # 心跳响应
                pass
                
            elif msg_type == "command":
                # 执行指令
                if self.on_command:
                    self.on_command(data.get("command"))
                    
            else:
                logger.warning(f"未知消息类型: {msg_type}")
                
        except json.JSONDecodeError:
            logger.error(f"无效的JSON消息: {message}")
    
    async def _disconnect(self):
        """断开连接"""
        if self._ws:
            await self._ws.close()
    
    def send_status(self, status: dict):
        """发送状态更新"""
        if self._ws and self.connected and self._loop:
            msg = {
                "type": "status",
                "device_id": self.device_id,
                "data": status
            }
            asyncio.run_coroutine_threadsafe(
                self._ws.send(json.dumps(msg)),
                self._loop
            )
```

```python
from PyQt6.QtCore import QObject, pyqtSignal
import logging

logger = logging.getLogger(__name__)


class CommandHandler(QObject):
    """指令处理器 - 将 WebSocket 指令转换为 UI 操作"""
    
    # 信号用于跨线程通信
    command_signal = pyqtSignal(dict)
    
    def __init__(self, window, playlist):
        super().__init__()
        self.window = window
        self.playlist = playlist
        
        # 连接信号
        self.command_signal.connect(self._execute_command)
    
    def handle(self, command: dict):
        """处理指令（从 WebSocket 线程调用）"""
        # 通过信号转发到主线程
        self.command_signal.emit(command)
    
    def _execute_command(self, command: dict):
        """执行指令（在主线程中运行）"""
        action = command.get("action")
        logger.info(f"执行指令: {action}")
        
        if action == "switch":
            # 切换到指定内容
            index = command.get("index", 0)
            self.window.switch_to(index)
            
        elif action == "next":
            # 下一个内容
            self.window.next_content()
            
        elif action == "prev":
            # 上一个内容
            self.window.prev_content()
            
        elif action == "play":
            # 开始轮播
            self.playlist.start()
            
        elif action == "pause":
            # 暂停轮播
            self.playlist.pause()
            
        elif action == "reload":
            # 重新加载配置
            self.playlist.reload()
            
        elif action == "set_content":
            # 动态设置内容（临时）
            content = command.get("content")
            if content:
                self.window._show_content(content)
                
        else:
            logger.warning(f"未知指令: {action}")
```

```python
        """开始轮播"""
        if not self.contents:
            logger.warning("播放列表为空")
            return

        self.window.switch_to(0)
        self._start_timer_for_current()
        logger.info("轮播已开始")
    
    def pause(self):
        """暂停轮播"""
        self.is_playing = False
        self.timer.stop()
        logger.info("轮播已暂停")
    
    def next(self):
        """下一个"""
        self.window.next_content()
        if self.is_playing:
            self._start_timer_for_current()
    
    def prev(self):
        """上一个"""
        self.window.prev_content()
        if self.is_playing:
            self._start_timer_for_current()
    
    def reload(self):
        """重新加载配置"""
        # 重新读取配置文件
        import yaml
        with open("config.yaml", encoding="utf-8") as f:
            self.config = yaml.safe_load(f)
        
        self.contents = self.config.get("contents", [])
        logger.info(f"配置已重新加载，共 {len(self.contents)} 个内容")
    
    def _on_timer(self):
        """定时器触发"""
        self.window.next_content()
        self._start_timer_for_current()
    
    def _start_timer_for_current(self):
        """根据当前内容设置定时器"""
        current = self.window.get_current_content()
        
        # 内容特定的时长，或默认间隔
        duration = current.get("duration")
        if duration is None:
            duration = self.interval / 1000  # 使用默认间隔
        
        # 对于视频，如果 duration 为 null，不设置定时器（等视频播完）
        if current.get("type") == "video" and current.get("duration") is None:
            # 可以通过媒体状态信号来触发下一个
            self.timer.stop()
        else:
            self.timer.start(int(duration * 1000))
```

#### 6.3.2 认证模块 (server/auth.py)

```python
"""
认证模块 - API Key 和 Token 管理
"""

import secrets
import hashlib
import jwt
from datetime import datetime, timedelta
from typing import Optional


class AuthManager:
    """认证管理器"""
    
    def __init__(self):
        # API Keys（从配置或数据库加载）
        self.api_keys = {
            "sk_default_key": "default",
            # 可以添加更多 API Key
        }
        
        # JWT 配置
        self.jwt_secret = secrets.token_hex(32)
        self.jwt_algorithm = "HS256"
        self.token_expire_hours = 24
    
    # ========== API Key 管理 ==========
    
    def validate_api_key(self, api_key: str) -> bool:
        """验证 API Key"""
        return api_key in self.api_keys
    
    def generate_api_key(self, name: str) -> str:
        """生成新的 API Key"""
        key = f"sk_{secrets.token_hex(16)}"
        self.api_keys[key] = name
        return key
    
    # ========== Token 管理 ==========
    
    def generate_token(self, device_id: str) -> str:
        """生成 Token"""
        payload = {
            "device_id": device_id,
            "exp": datetime.utcnow() + timedelta(hours=self.token_expire_hours),
            "iat": datetime.utcnow()
        }
        return jwt.encode(payload, self.jwt_secret, algorithm=self.jwt_algorithm)
    
    def validate_token(self, token: str) -> Optional[str]:
        """验证 Token，返回 device_id 或 None"""
        try:
            payload = jwt.decode(token, self.jwt_secret, algorithms=[self.jwt_algorithm])
            return payload.get("device_id")
        except jwt.ExpiredSignatureError:
            return None
        except jwt.InvalidTokenError:
            return None
    
    def refresh_token(self, current_token: str, device_id: str) -> Optional[str]:
        """刷新 Token"""
        # 验证当前 Token（即使过期也可以刷新）
        try:
            payload = jwt.decode(
                current_token, 
                self.jwt_secret, 
                algorithms=[self.jwt_algorithm],
                options={"verify_exp": False}  # 允许过期 Token 刷新
            )
            
            if payload.get("device_id") != device_id:
                return None
            
            # 生成新 Token
            return self.generate_token(device_id)
            
        except jwt.InvalidTokenError:
            return None
    
    def revoke_token(self, token: str):
        """撤销 Token（可以将 Token 加入黑名单）"""
        # 简化实现：可以维护一个黑名单
        pass
```

#### 6.3.3 设备管理器 (server/device_manager.py)

```python
"""
设备管理器 - 支持持久化
"""

import json
from datetime import datetime
from pathlib import Path
from typing import Optional, List, Dict
import uuid


class DeviceManager:
    """设备管理器"""
    
    def __init__(self, storage_file: str = "devices.json"):
        self.storage_file = Path(storage_file)
        self.devices: Dict[str, dict] = {}
        self._load()
    
    def _load(self):
        """从文件加载设备数据"""
        if self.storage_file.exists():
            try:
                with open(self.storage_file, 'r', encoding='utf-8') as f:
                    data = json.load(f)
                    self.devices = data.get("devices", {})
            except Exception:
                self.devices = {}
    
    def _save(self):
        """保存设备数据到文件"""
        try:
            with open(self.storage_file, 'w', encoding='utf-8') as f:
                json.dump({
                    "devices": self.devices,
                    "updated_at": datetime.now().isoformat()
                }, f, indent=2, ensure_ascii=False)
        except Exception as e:
            print(f"保存设备数据失败: {e}")
    
    def register(self, name: str, location: str = None) -> tuple:
        """注册设备，返回 (device_id, token)"""
        # 查找是否已存在同名设备
        for device_id, device in self.devices.items():
            if device["name"] == name:
                # 恢复已有设备
                device["connected"] = True
                device["last_seen"] = datetime.now().isoformat()
                self._save()
                return device_id, device.get("token")
        
        # 创建新设备
        device_id = str(uuid.uuid4())[:8]
        token = secrets.token_hex(16)  # 简化：实际应使用 AuthManager 生成
        
        self.devices[device_id] = {
            "id": device_id,
            "name": name,
            "location": location,
            "connected": True,
            "last_seen": datetime.now().isoformat(),
            "current_content": None,
            "token": token,
            "created_at": datetime.now().isoformat()
        }
        
        self._save()
        return device_id, token
    
    def set_offline(self, device_id: str):
        """设置设备离线"""
        if device_id in self.devices:
            self.devices[device_id]["connected"] = False
            self._save()
    
    def update_last_seen(self, device_id: str):
        """更新最后在线时间"""
        if device_id in self.devices:
            self.devices[device_id]["last_seen"] = datetime.now().isoformat()
    
    def update_status(self, device_id: str, status: dict):
        """更新设备状态"""
        if device_id in self.devices:
            self.devices[device_id].update(status)
            self.devices[device_id]["last_seen"] = datetime.now().isoformat()
    
    def get(self, device_id: str) -> Optional[dict]:
        """获取设备信息"""
        return self.devices.get(device_id)
    
    def exists(self, device_id: str) -> bool:
        """检查设备是否存在"""
        return device_id in self.devices
    
    def list_devices(self) -> List[dict]:
        """获取所有设备列表"""
        return list(self.devices.values())
    
    def remove(self, device_id: str):
        """移除设备"""
        if device_id in self.devices:
            del self.devices[device_id]
            self._save()
```

```python
# 播放历史记录
class PlayHistory:
    def __init__(self):
        self.history_file = "play_history.json"
        self.history = self._load()
    
    def record(self, device_id: str, content: dict):
        """记录播放历史"""
        entry = {
            "device_id": device_id,
            "content": content,
            "timestamp": datetime.now().isoformat()
        }
        self.history.append(entry)
        self._save()
    
    def get_device_history(self, device_id: str, limit: int = 100):
        """获取设备播放历史"""
        return [h for h in self.history if h["device_id"] == device_id][-limit:]
    
    def _load(self):
        if Path(self.history_file).exists():
            with open(self.history_file, 'r', encoding='utf-8') as f:
                return json.load(f)
        return []
    
    def _save(self):
        with open(self.history_file, 'w', encoding='utf-8') as f:
```

### 10.4 系统屏保集成

将程序注册为 Windows 系统屏保：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      系统屏保集成流程                                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   1. 编译/打包                                                          │
│      screensaver_scr/main.py → screensaver.scr                         │
│                                                                         │
│   2. 安装（管理员权限或用户安装）                                        │
│      复制 .scr 文件到 Windows 系统目录                                   │
│      或通过注册表指向 .scr 文件路径                                     │
│                                                                         │
│   3. 用户在系统设置中选择                                                │
│      控制面板 → 外观 → 屏幕保护程序 → 选择 "ScreenSaver"                │
│                                                                         │
│   4. 系统调用参数                                                        │
│      /s  - 正常屏保模式（全屏显示）                                      │
│      /c  - 配置模式（显示设置对话框）                                    │
│      /p  - 预览模式（在预览窗口中显示）                                  │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

```python
# 注册为系统屏保
import winreg
import shutil
from pathlib import Path

def register_as_screensaver(scr_path: str):
    """注册为 Windows 系统屏保"""
    
    # 方法1: 复制到系统目录（需要管理员权限）
    system_dir = Path(os.environ['SYSTEMROOT']) / 'System32'
    dest = system_dir / 'screensaver.scr'
    shutil.copy(scr_path, dest)
    
    # 方法2: 修改注册表（用户级别）
    key = winreg.OpenKey(
        winreg.HKEY_CURRENT_USER,
        "Control Panel\\Desktop",
        0,
        winreg.KEY_SET_VALUE
    )
    
    winreg.SetValueEx(key, "SCRNSAVE.EXE", 0, winreg.REG_SZ, str(Path(scr_path).absolute()))
    winreg.CloseKey(key)
```

### C. 常见问题

**Q1: WebSocket 连接失败怎么办？**

检查以下几点：
1. 服务器是否启动
2. URL 是否正确（wss:// 而非 ws://）
3. 防火墙是否允许出站连接
4. Token 是否正确

**Q2: .scr 屏保无法连接到常驻应用？**

确保：
1. 常驻应用正在运行（托盘图标可见）
2. IPC 服务已启动
3. 命名管道名称一致

**Q3: 视频播放没有声音？**

确保：
1. 系统音量未静音
2. 音频输出设备正确
3. 视频文件包含音频轨道

**Q4: 如何调试客户端？**

查看日志文件 `screensaver.log`，或设置 `QT_DEBUG_PLUGINS=1` 环境变量。

**Q5: 如何更换内容？**

两种方式：
1. 手动替换 `contents/` 目录下的文件
2. 通过 Web 控制面板远程推送
